Export or share

Five ways out. The first two are files you keep; the rest are for handing the list to someone else.

  • A standalone .html file to host anywhere. Covers stay links, hover cards work, and it can be imported back here.

  • A .png to paste into Reddit or Discord. Covers come from the local store, so press Save covers first.

  • A URL that rebuilds this list in someone else's browser. The list travels in the part of the address that is never sent to any server.

  • Every title stays a clickable link inside the post itself — no image, no page to host.

  • The document itself. This is the copy you own; everything else is generated from it.

Share link

The whole list is encoded in the link after the #, which browsers never send to a server — so nobody, including whoever hosts this copy, sees what you ranked. By default the link opens a reading page: covers, hover cards and working links, with a button to take a copy into the editor.

Post to Reddit

A Reddit post can carry an image or clickable links — never both, whatever tool made it. So post the image, and put the links in the first comment. The number on each cover matches the number beside its title below.

  1. Download the image

    Titles under the covers and a number on each one, so nobody has to squint at the art to work out what a book is.

  2. Start an image post on r/litrpg

    Choose Images, upload the file, give it a title, and post it.

  3. Paste this as the first comment

“Text post instead” opens Reddit's form with the title and this comment already filled in — no image, but every title stays a link. Check the subreddit's rules before posting either way.
